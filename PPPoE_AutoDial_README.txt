========================================================================
 寬頻(PPPoE)自動撥號設定工具 v1.0
 PPPoE_AutoDial_v1.0.bat / PPPoE_AutoDial_v1.0.ps1
========================================================================

【這是什麼】
 讓一台 Windows 開機自動撥寬頻(PPPoE),斷線自動重撥。
 主要用途:Hyper-V 的 VM 各自撥自己的 PPPoE。

【在哪台機器跑】
 ★ 在「要撥號的那台機器裡面」跑,不是在 Hyper-V 主機上跑。
 工具偵測到主機的 vmms 服務時會在上方顯示紅字警告。
 把 .bat + .ps1 兩個檔複製進 VM(可用 VM_FileSync 的 Copy-VMFile 路線,
 不需要 VM 帳密),在 VM 內雙擊 PPPoE_AutoDial_v1.0.bat(會跳 UAC 提權)。

------------------------------------------------------------------------
 前提:這三件事不成立,怎麼設都撥不通
------------------------------------------------------------------------
 1. 主機用「有線網卡」接到「橋接模式」的數據機。
    小烏龜/數據機自己在路由模式撥號的話,VM 撥不到 PPPoE 伺服器。
 2. 主機建一張「外部 (External)」虛擬交換器綁那張有線網卡,VM 改接它。
       New-VMSwitch -Name "External" -NetAdapterName "乙太網路" -AllowManagementOS $true
       Connect-VMNetworkAdapter -VMName "1" -SwitchName "External"
 3. Default Switch(NAT)與 Wi-Fi 都不行。
    PPPoE 不是 IP 封包,Hyper-V 對無線網卡只搬 IP 流量,PPPoE 過不去;
    無線路由器也會把 PPPoE 終結掉,到不了 ISP。

 曾經卡住的坑:「網路連線」裡若有「網路橋接器」、網卡顯示「橋接的」,
 Hyper-V 就無法把外部交換器綁上去 -> 先右鍵刪掉那個橋接器。

 若 ISP 要求 VLAN tag,在 Hyper-V 該 VM 的「網路介面卡 -> VLAN」填 VLAN ID。
 建議順手把 VM 網卡 MAC 設成靜態(預設是動態,重開機會換):
       Set-VMNetworkAdapter -VMName "1" -StaticMacAddress "00155D010101"

------------------------------------------------------------------------
 使用步驟
------------------------------------------------------------------------
 步驟 1  選擇寬頻連線項目
   ★ 一定要先手動建立一次。rasdial 只能撥「已存在的連線項目」,
     Windows 沒有建立 PPPoE 連線的官方指令(Add-VpnConnection 只做 VPN),
     所以本工具不自己產生 rasphone.pbk(該檔格式無官方文件、隨版本變動,
     硬寫容易生出「看得到卻撥不動」的殘廢項目)。

   按「開啟建立連線精靈」-> 連線到網際網路 -> 寬頻 (PPPoE) -> 填 ISP 帳密。
   兩個勾選漏了後面一定失敗:
     [v] 記住這個密碼
     [v] 允許其他人使用這個連線
         ^ 這會把項目寫進「全機電話簿」
           C:\ProgramData\Microsoft\Network\Connections\Pbk\rasphone.pbk
           不勾的話只存在 %AppData%,排程用 SYSTEM 跑會回錯誤 623。

   ★ 連線名稱請取「純英數」(例:PPPoE),不要用預設的「寬頻連線」。
     .bat 內容含中文會被 cmd 用 cp950 逐位元組解析而錯亂、還會吃掉相鄰行。
     工具偵測到中文名稱會擋下不給安裝。

   建好後按「重新掃描」。清單會顯示每個項目在哪本電話簿:
     [全機 / 寬頻 PPPoE]  <- 正確
     [個人 / 寬頻 PPPoE]  <- SYSTEM 讀不到,會紅字警告

 步驟 2  測試撥號
   「撥號(用連線內建帳密)」= rasdial 不帶帳密。這個能通最好,
   代表步驟 3 可以選「dial.bat 不寫帳密」,硬碟上就不會有明碼密碼。
   通不了才改用「撥號(用上面帳密)」測試。
   結束代碼就是 RAS 錯誤碼,工具會翻成中文,常見的:
     623 找不到電話簿項目(多半是連線建在「個人」電話簿)
     678 遠端電腦沒有回應(找不到 PPPoE 伺服器 -> 檢查前提 1、2)
     691 帳號或密碼錯誤
     769 網路介面卡被停用
     756 這個連線已經在撥了

 步驟 3  安裝自動撥號
   會做三件事:
     (a) 寫 C:\pppoe\dial.bat(純 ASCII、goto 結構、不用 ( ) 區塊)
     (b) 建排程 PPPoE-AutoDial-Boot   觸發=電腦啟動時 + 延遲 N 秒
     (c) 建排程 PPPoE-AutoDial-Watch  觸發=每 1 分鐘(斷線自動重撥)
   兩個排程都以 SYSTEM 執行。
   ★ 為什麼是 SYSTEM:這批 VM 的 admin 帳號沒有密碼,Windows 不准空密碼
     帳號做非互動登入,用該帳號設「不論使用者是否登入都執行」一定失敗。
     (同一個原因害 PowerShell Direct 也連不進去。)

   dial.bat 的邏輯:先問「PPPoE 這條連線在不在」(rasdial 不帶參數會印出
   已連線的項目名稱,用 find 比對名稱),在就直接結束、不在才撥。
   每次結果附時間戳寫進 C:\pppoe\dial.log,超過 1MB 自動清掉重來。

   ★ 守衛條件不能用「ping 得通就不撥」(v1.0 初版踩過):
     VM 通常還有另一條對外路(外部交換器直接跟路由器拿 IP),
     PPPoE 斷線時 ping 8.8.8.8 照樣通 -> 守衛永遠成立 -> 永遠不會撥號。
     要問的是「這條撥號連線在不在」,不是「有沒有網路」。
     比對項目名稱(ASCII)而不是解析在地化狀態文字,才不會被語系影響。

   選「dial.bat 寫入帳號密碼」的話密碼是明碼,工具會用 icacls 把
   C:\pppoe 權限收到只有 SYSTEM 與 Administrators 可讀(用 SID 指定,
   避開中文語系帳號名稱對不上的問題)。

 驗證
   ★ 先按「中斷連線」,讓 PPPoE 處在離線狀態,再按「以 SYSTEM 立即試跑一次」。
     連著撥號的時候按,dial.bat 只會記一行 already connected, skip,什麼都沒驗到。
   它用 schtasks /Run 觸發開機那個工作,等 8 秒後把 dial.log 的新增行印出來。
   這一步是在驗「SYSTEM 讀不讀得到電話簿」——手動撥得通但 SYSTEM 撥不通(623)
   是最常見的失敗。看到 dial exit=0 就成了。

------------------------------------------------------------------------
 多撥(每台 VM 各自對外 IP)的老實話
------------------------------------------------------------------------
 - 一組 ISP 帳號通常只允許一條 session,第二台 VM 用同一組帳號撥
   會把第一台踢掉。要每台各自對外 IP,得 ISP 支援多 session 或
   申請多組帳號 —— 這點請自行向 ISP 確認或實測,本工具無法判斷。
 - 主機自己如果也在撥,那也算一條。
 - 外部交換器本身「不會」給你多個對外 IP,只是讓 VM 各自進得了實體網路。

------------------------------------------------------------------------
 手動指令對照(不想開 GUI 時)
------------------------------------------------------------------------
   rasdial                                   列出目前已連線的項目
   rasdial PPPoE 帳號 密碼                    撥號
   rasdial PPPoE /DISCONNECT                 中斷
   schtasks /Query /TN PPPoE-AutoDial-Boot   查排程
   schtasks /Run   /TN PPPoE-AutoDial-Boot   立刻以 SYSTEM 跑一次
   schtasks /Delete /TN PPPoE-AutoDial-Boot /F
   schtasks /Delete /TN PPPoE-AutoDial-Watch /F
